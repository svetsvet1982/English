# 2부 8화 "The Calendar" — 연속성 메모

- 날짜: 2030년 1월 21일(월, 마틴 루서 킹 데이 — 연방 공휴일, 건물 거의 빔). 07:00 진짜 방 → 07:40 부장관실 아르준 통화(델리 18:00) → 09:30 진짜 방 루이즈 요원 → 11:00 장관 집무실 → 19:30 부장관실 데이턴 통화.
- **가짜 일정표 4종(카나리아 트랩)**: 1/15(화) 밤 작성, **1/16(수) 18:00 배포**, 부장관의 1/21 주간 일정. 회의·시간은 같고 가짜 출장 하나씩. 총 31명(7화의 31명과 일치).
  - A: NSC 걸프 실무반 9명 — 1/23(수) 도하, 카타르 중재자
  - B: 국방부 연락반 6명 — 1/22(화) 푸자이라, 인도 호위함 승선
  - **C: 장관실 4명(캘러웨이·비서실장·장관 일정 책자 담당 비서·피터 보이트) — 1/24(목) 제네바, 이란 측 비공개 면담, 'B 살롱'(Salon B, 일라이어스가 화요일 밤 지어냄)**
  - D: 우리 쪽 12명(부장관실+근동국) — 1/25(금) 콜롬보, 아르준 메타
  - PDF마다 추적 신호(beacon) 삽입.
- 사미라: 미끼는 F 목록이 아니라 새 페이지 **'Bait'(미끼)**에 기록(변호사용: 어떤 거짓말을 누구에게 언제).
- 7화 결과: 1/16 칼리드가 진짜 방 확인 → 1/18(금) 최고국가안보회의에 '창문 없음' 전달, **무스카트 트랙 유지, 캄란 자리 유지.** 캘러웨이는 TV에서 "does not seek"만. **'will not' 미래 시제는 일라이어스의 결과 보고에 그의 이름으로만** 캄란에게 전달("My words, my neck").
- **유출된 가짜(F 번호 미기재)**: 1/20(일) 21:12(동부) 38초 합성 음성, 인도 뉴스 채널 + 왓츠앱 단체방 약 200곳. 전문: "Geneva's Thursday. Salon B, just Kamran and me. Nobody from Delhi in the room. The Indians can read the readout afterwards, like everybody else." → C 버전만 나옴. A·B·D는 아무 흔적 없음.
- 아르준(통화): "Delhi has taken note" = 이름을 공책에 적었다(1971년 7함대도 기억). 일라이어스가 사미라의 만류를 어기고 미끼 방식을 털어놓음(B 살롱은 존재하지 않음 → 클립이 스스로 가짜임을 증명). 아르준 값: **인도 호위 작전의 미국 연락반 위치 보고 공유를 금요일(1/25)까지 동결**, 그때까지 유출 부서 이름 요구. 정보 이동(아르준→일라이어스): 클립은 방송 5분 전 **두바이 미디어 대행사의 '걸프 특파원'** 이메일로 인도 방송국에 도착(7화 캄란 정보와 같은 도시·같은 종류) — "same orchestra".
- 루이즈 특별요원(외교안보국 방첩과, 이 건은 장관실에 보고): C 버전은 4개 계정 중 3개는 열람만, **보이트 계정이 1/17(목) 23:52 개인 웹메일(대학 때 만든 판타지 풋볼용 주소)로 전달. 90초 뒤 C 버전 PDF가 두바이의 한 주소에서 열림**(추적 신호). 그 뒤 경로는 동의·영장 없이 확인 불가. "You're building a pattern. I'm building a case." 일라이어스가 1부의 브랜트 항공편 번호(장관실만 보유)·서울 호텔 환기구(예약 전 개방) 패턴 언급.
- 장관실: 보이트 해명 "장관 책자 인쇄하려고 집으로 보냄, 여기 프린터는 밤 10시 이후 걸림, 다들 그렇게 함." 두바이엔 아는 사람 없다고 부인. 캘러웨이 **"Mistakes were made, Peter. You made them." 출입증 책상에, 접근 권한 정오 종료 — 약 9분 만에 해임.** 일라이어스가 "직원 신분일 때 면담 먼저"를 요청, 루이즈도 2시간 면담 요청 → 캘러웨이 거절("편지를 보내"). 보고서 참조는 부장관만.
- 워터게이트 공방: 캘러웨이 "닉슨은 침입도 몰랐는데 쫓겨났다" → 일라이어스: 1972-06-23 테이프(홀더먼, CIA로 FBI 압박), 하워드 베이커의 질문. 캘러웨이: "What did I know? 내 보좌관이 부주의했다는 것." **"앞으로 자네 일정은 나한테 직접. 보좌관도 PDF도 없이."**
- 일라이어스 → 아르준 금요일 답(계획): "유출은 장관실 받은편지함 하나, 당사자 오늘 해임, 조사 계속."
- 사미라의 새 페이지: '버지니아' 밑이 아니라 따로 **"Who was in a hurry?"(누가 서둘렀나?)**.
- 가족: 로지는 MLK 데이에 푸드뱅크 봉사(프랭크 동행, 1968년 4월 얘기 40분). 프랭크 당시 15세 "그날 밤 우리 동네가 조용해졌다". 로지: 반 친구가 인도 클립 진위를 묻자 "아빠는 'like everybody else'를 안 쓴다(통금 얘기하다 한 번 쓰고 사과함)". 프랭크 마지막 말: "그럼 네가 직접 물어봐라. 누가 묻지 말라고 한 다음 날에."(보이트를 가리킴, 후속 미정)
- (편집) 102 "Sir, with all due respect, not this morning." / "오늘 오전엔 안 됩니다"('Not yet, sir' 카운트와 충돌 방지). 살롱 B 클립 = F-8(요약 정본).
