## 핵심 표현 정리 (낭독하지 않음)

- **chain of custody** — 증거 보관의 연속성(누가 언제 증거를 만졌는지 끊김 없이 증명하는 것) / 012
- **teardown** — 분해 분석 / 026
- **firmware** — 펌웨어(기계 안에 박혀 기계를 움직이는 명령어) / 041
- **read protection** — (칩의) 읽기 보호 / 045
- **debug port / debug cable** — 디버그 포트 / 케이블(개발용 접속구) / 047
- **in a (big) hurry** — (아주) 급하게 / 049, 054–055
- **reverse-engineer** — 역설계하다 / 061
- **work backward** — 거꾸로 짚어 가다 / 061
- **fingerprint** — (고유한 흔적으로서의) 지문 / 074
- **by accident** — 실수로, 우연히 / 076
- **fool oneself** — 스스로를 속이다 / 088
- **smoking gun** — 결정적 증거 / 106–107
- **look someone in the eye** — 상대의 눈을 똑바로 보다(정면으로 책임지게 하다) / 142, 144

## 현안 메모 (낭독하지 않음)

- 영업비밀 분쟁에서 '같은 실수'는 강력한 정황 증거가 된다. 독립적으로 개발한 두 제품이 같은 물리 원리를 따를 수는 있어도, 같은 오타나 같은 숨은 서명(카나리아)을 공유할 가능성은 거의 없기 때문이다. 소프트웨어 업계에서는 이런 장치를 '카나리아' 또는 '워터마크'라고 부른다.
- 증거는 수집 방식이 내용만큼 중요하다. 구매 영수증, 미개봉품 보관, 개봉 과정 녹화, 원본 복제 전 전문 업체 입회 같은 '증거 보관의 연속성'이 무너지면 법정에서 증거 능력이 약해진다(→4부 2화).
