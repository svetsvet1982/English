## 핵심 표현 정리 (낭독하지 않음)

- **escort required** — 에스코트(동행) 필수, 출입 권한 없는 방문자는 보안요원이 따라붙음 / "Visitor. Escort Required." (015)
- **with a grudge** — 앙심을 품은, 원한이 있는 / "You're a retired analyst with a grudge." (029)
- **Walk me through it.** — 처음부터 차근차근 말해 봐 / 테스의 말버릇 (007)
- **budget object class code (BOC)** — 예산 객체 코드, 정부 지출의 품목 분류 번호("영수증의 품목 분류 같은 것") (048~049)
- **fiscal year** — 회계연도, 미국 연방 정부는 10월 1일 시작 / "The fiscal year that started in October 2018." (055)
- **wet signature** — 잉크로 직접 한 서명(전자 서명의 반대) (057)
- **registry number** — 문서 등록 번호, 기록부의 한 줄 / "Pull the logbook… Read line 1207." (061)
- **access log** — 접근 로그, 누가 언제 어떤 파일을 몇 분 열었는지 남는 기록 (074~076)
- **voice clone** — 음성 복제, 녹음으로 사람 목소리를 흉내 낸 AI 음성 (084~086)
- **mole hunt** — 두더지 사냥, 기관 내부의 배신자(첩자) 색출 작업 (093~096)
- **clean your own house** — 자기 집안(조직) 문제를 스스로 정리하다 (118)
