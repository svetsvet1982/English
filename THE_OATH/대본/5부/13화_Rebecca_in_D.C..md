- **contract award** — 계약 발주(낙찰) / (009, 102)
- **FOIA (Freedom of Information Act)** — 정보공개법 / (019, 088)
- **inspection report** — 점검 보고서 / (019, 088)
- **on background** — 배경 정보로(출처를 밝히지 않는 조건) / (033, 034)
- **second source** — 두 번째 취재원 / (039)
- **public records only** — 공개 기록만 / (046, 051)
- **conflict of interest** — 이해충돌 / (049, 050)
- **embargo** — 보도 유예 / (056)
- **enter into the record** — 기록에 넣다 / (088)
- **corrective plan** — 시정 계획 / (097)
- **contract modification** — 계약 변경 / (103)
- **a fair summary** — 공정한 요약 / (107)
- **take the question back / respond for the record** — 질문을 가져가 기록으로 답변하다 / (114)
- **in writing, within thirty days** — 30일 안에 서면으로 / (113, 116)
