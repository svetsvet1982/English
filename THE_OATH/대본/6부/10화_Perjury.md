## 핵심 표현 정리 (낭독하지 않음)

- **correct the record** — 기록을 정정하다 / (010, 027)
- **legal hold** — 법적 보존 조치(자료 삭제 금지 명령) / (020)
- **report up the ladder** — 상부로 보고하다(이사회까지) / (022, 023)
- **audit committee / independent directors** — 감사위원회 / 독립 이사 / (022)
- **My client is the company.** — 내 의뢰인은 회사다 / (028)
- **retaliation complaint** — 보복 진정 / (042)
- **false statements (18 U.S.C. 1001)** — 허위 진술(죄) / (051, 090)
- **material** — 중대한(결정을 바꿀 수 있는) / (052, 053)
- **perjury / willfully** — 위증 / 고의로 / (055)
- **"I don't recall."** — "기억나지 않습니다"(위증의 방어) / (034, 056, 057)
- **criminal referral / refer to the Justice Department** — 형사 회부 / 법무부에 회부하다 / (060, 061, 090)
- **A referral isn't a verdict. It's a door.** — 회부는 판결이 아니라 문이다 / (062)
- **place on leave / resign** — 직무 정지하다 / 사임하다 / (098)
- **501(c)(4)** — 기부자 공개 의무가 없는 '사회복지' 비영리 단체 / (140)
