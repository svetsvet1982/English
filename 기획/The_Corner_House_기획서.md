# 《The Corner House》 영어 연속 대화문 기획서

> 브루클린 레드훅, Van Brunt Street 모퉁이 4층 벽돌 건물의 1년 하고도 한 계절(2026년 3월~2027년 6월). 미국인끼리의 구어 낭독 연습용. 원작 기획 《Het Hoekhuis》(암스테르담)의 뉴욕 각색판.

> 원본 데이터는 같은 폴더의 `.xlsx` 파일입니다(진행 현황 자동 집계 포함). 이 문서는 GitHub에서 읽기 쉽게 옮긴 사본입니다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 배경 | 브루클린 레드훅 Van Brunt Street 모퉁이의 4층 벽돌 건물(가상의 주소). 1층 동네 바 'The Hook'과 전기자전거 수리점 'Bell Bikes', 2층 토미의 집·에스포지토 부인, 3층 에디·제시가 얹혀사는 친구 집, 4층 마리솔과 디에고·몇 년째 비워 둔 빈집 + 학교, 회사, 병원, 해변, 시청, 커뮤니티 보드, 스케이트장 |
| 왜 레드훅인가 | 레드훅의 이름은 네덜란드 식민지 시절 'Roode Hoek(붉은 모퉁이)'에서 왔다. 원작의 'Hoekhuis(모퉁이 집)'와 이어지는 지명이며, 부두 노동자 동네 → 젠트리피케이션, 2012년 허리케인 샌디 침수, 지하철이 닿지 않는 교통 사각지대 등 미국 현안이 한곳에 모여 있다 |
| 기간 | 2026년 3월(성 패트릭 데이 무렵) ~ 2027년 6월. 1부 봄 → 2부 여름 → 3부 가을 → 4부 겨울 → 5부 이듬해 봄 |
| 분량 | 총 5부 × 18화 = 90화 |
| 화당 길이 | 120턴 (화자 발화 1회 = 1턴, 지문은 턴 수에 포함하지 않음) |
| 총 분량 | 10,800턴 |
| 턴 번호 | 표기하지 않음 (TOMMY: 처럼 화자 이름으로만 구분) |
| 화자 수 | 한 화 2~4명. 바 장면은 최대 5명 |
| 구성 원칙 | 미국의 한 해 달력(성 패트릭 데이, 메츠 개막전, 메모리얼 데이, 독립기념일 250주년, 핼러윈, 중간선거, 추수감사절, 슈퍼볼 등)을 따라가는 군상극. 화마다 주인공 인물이 바뀜. 큰 줄기는 '사모펀드에 팔린 건물을 세입자들이 협동조합으로 되사기' |
| 미국 현안 | 2025~2026년 미국·뉴욕의 실제 현안(임대료·주거난, 관세와 물가, AI와 일자리, 보험료 급등, 이민 단속 불안, 기후 재난, 배달 노동 등)을 인물의 생활 문제로 반영 ('미국 현안 반영' 시트) |
| 난이도 | A2~C1 혼합 ('난이도 설계' 시트 비율표) |
| 한글 해석 | 각 화 맨 마지막에 대화 순서대로 수록 |
| 낭독 용도 | 각 화에 낭독 포인트(플랩 T, 연음, 약형, 축약 gonna/wanna, th, r/l, 강세·억양, 뉴욕 모음)를 명시 ('화별 개요' H열) |
