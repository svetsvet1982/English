# 4부 7화 "Old Friends" — 새로 확정한 연속성 설정

- 날짜: 12월 4일(월) 오후 뉴욕 워싱턴 스퀘어 공원 체스 테이블(표류 14일째, 5달러 내기 테이블, 톰은 개선문 쪽) → 12월 5일(화) 오전 '벽장'(아나 화상) → 12월 5일 밤(오슬로 23시) 잉그리드 통화 → 12월 6일(수) 06:30 프랭크 통화 → 12월 6일 10:00(베이징 23:00) 저우 한·멍 대령 통화. 표류 1일째 = 11월 21일 → 17일째 = 12월 7일.
- 드미트리: 15시 안보리 회의 참석차 뉴욕(공식 '분노' 원고). 초대 카드 "Bring the board and a map." 러시아 레이더 위성의 14일 치 해상 바람·해류 자료(6시간 간격) + **9일째 '작고 따뜻한 점'**(미·중 수색 구역에서 110km). 러시아는 금요일(12/1) 무관을 통해 베이징에 직접 제안 → 거절("엉뚱한 사촌"). 그래서 일라이어스가 출처를 숨기고 전달("세탁"/"외교"). 값은 없음. 조건: 보고·전문·감사 전화 없음, 7층에 한마디도 올리지 말 것.
- **정보 이동**: 11월 29일(수) Orbis Lens가 모스크바 민간 재판매상에게 같은 위성 영상의 **30일 독점권 + 베이징·워싱턴 판매 금지 조항**을 정가 3배에 제안 → 재판매상이 드미트리 사무실에 신고. 12월 6일 브라질 파일 공개 20분 뒤 Orbis Lens가 상자 구역 상업 위성 영상 72시간 치를 전부 구매(톰).
- 체스: 일라이어스가 또 수비적인 수(기보 미기재). 가짜 속담 "싸구려 판이 정직한 선수를 만든다."
- 아나: 알칸타라 개방 센터 소장(여성, 이름 미정)의 팀이 토요일(12/2)부터 자발적으로 분석. **12일째(12/2) 현지 10:41, 파트너 위성 광학 촬영에 1초 미만 밝은 픽셀 4개 = 신호 거울 반사 추정.** 조건: ① 베이징도 같은 순간 브라질에게서 파일 수령 ② 분석은 규칙대로 제출 24시간 뒤 공개 — 12/6 11:00 브라질리아 = 남중국해 22:00 = 워싱턴 09:00. 일라이어스가 '하루 유예'를 가정법으로 떠봤다가 철회(규칙이 자신에게도 버티는지 시험). 카이우가 일라이어스 피아노 녹음을 원함("외교관처럼 친다, 쉼표가 많다").
- 잉그리드: 오슬로 기상연구소에서 **OpenDrift**(실재하는 노르웨이 기상연구소의 오픈 소스 표류 모델)로 계산. 미 해군 모델 = 바다닻 있는 보트 가정(해류), 중국 = 보트 없는 사람 가정. 실제는 닻 잃은 보트 + 12월 북동 계절풍 → 남서쪽, 파라셀 가장자리 암초 쪽. 가상 보트 5천 개 중 9일째·12일째 점을 모두 지난 312개 → **상자 30×12해리, 이름 없는 모래톱 3개**. 러시아 바람 자료임을 짐작하지만 이름 말 안 함.
- **매기 → 잉그리드**: 12월 2일(토) 20년 만에 처음 직접 전화. "아시아 비상 대비 자료" 문의 + "탈린 이후 그랜트한테 연락 왔냐." 잉그리드는 그때 사실대로 '없다'. 다음엔 "말을 아낄 것". 일라이어스: "그런 게 생기면 당신도 그 방에"(1부 7화 약속 재확인).
- 프랭크: 수술 2주 뒤 심장 재활 6바퀴(크리스마스까지 8바퀴 목표), 코왈스키 부인이 운전·동행. 로지가 뉴욕 일 이후 매일 밤 9시 할아버지에게 전화. 존 헤이(링컨 개인 비서 → 국무장관), "이번엔 중국이 펜을 쥐게 하라".
- 저우 한·멍 대령: 직원들이 지도를 '문호 개방 정책'이라 비꼼. 중국 배 2척 싼야 출항(통화 40분 전), "중국 배, 중국 지휘 = 레드 라인". 미 구축함은 상자 동쪽 60마일, 헬기 탑재. 충돌 방지 채널 = **16번 채널, 영어, 짧게**. 멍: "헬기 요청 안 함" / 저우: "오늘은. 내일은 누구 헬기가 가장 가까운지 보자."
- 지도는 베이징·브라질리아·오슬로에 같은 순간 발송(주인 없는 지도). 매기에게는 보고하지 않음.
