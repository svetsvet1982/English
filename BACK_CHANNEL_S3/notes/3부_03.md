# 3부 3화 "Langley Wants Him" — 연속성 메모 (2027-05-19 수, 몬트리올, 비)

- 09:00 4번 창구, 번호표 '7' = 단역 **클로에 루아**(19, 콩코디아 간호학과 2학년, J-1 메인주 여름 캠프 지도교사 7주, 카누 강사, 할머니 "미국 남자랑 결혼하면 귀신 돼서 쫓아다님") → 승인.
- 09:15 피에르뤽이 ACS에서 뒤 계단으로 올라옴: 로비에 오타와발 남자 둘, 외교관 번호판, 한 명은 "정무과치곤 너무 좋은 구두". 일라이어스의 거짓말: "7월 4일 리셉션 깃발 때문". 피에르뤽은 안 믿음("약속이 아니라 일기예보").
- 10:00 영사관 **6층 보안 회의실**(점검 완료): **그레그 머서**("오타와 대사관 정무과" = CIA, 좋은 구두) + 동행 1명(대사 없음). 글로리아 배석.
  - 랭글리의 계획: 루킨은 **7월 23일까지 '현직 망명자(defector in place)'**로 암호실 근무를 계속하며 정보 제공 → 23일 버지니아로, 장기 디브리핑·새 이름·잔디밭 집. 주재국(캐나다)엔 "적절한 시점에" 통보.
  - 머서가 아는 것: **4월 26일 모스크바발 캐나다 공관 앞 전문, 9쪽, 머리말 단어 '아이들'·'캐나다의 친척'** ("We can read envelopes, not letters." 내용은 못 읽음). 해독자가 2주 뒤 가방 들고 옴 → 추론.
  - **일라이어스가 인정한 범위**: "봤다, 만지지 않았다, 복사 안 했다" + 우크라이나 아이들 명단, "이백 명 남짓", 이름·생년월일·코드·후견 가정·캐나다 친척 칸. **정확한 숫자 214·마크심·6월 1일 지시문 원문은 말하지 않음**(6월 1일 '활동적 친척' 보고 기한은 논거로 말함).
  - 머서의 산수: 모스크바에 명단 보유를 '조용히 알리고' 경계선·포로·부속서에서 진전 → 아이들은 "결국" 거래의 일부로 귀환. 아벨–파워스 "깔끔한 일대일" 왜곡 → 일라이어스 정정(프라이어, 21개월, 브루클린 보험 변호사 도노번, 어른 대 아이). 빈 지갑 칸·엽서("엉뚱한 사무실로 간 상자") 언급, 뒷면 문장 인용.
  - 일라이어스: "A list you hide is a list they re-code." 유통 기한 6월 1일 = **12일 남음**.
  - **머서의 공갈**: 감찰 통보서 + "공원 벤치에서 이란인 만나는 비자 담당" → "Files are thin until somebody feeds them." / "날씨 설명".
  - **글로리아의 첫 편들기(공관장 권고 전문)**: ① 워크인은 주재국 정부가 아는 상태에서 처리 ② 그의 문서를 협상 수단으로 쓰지 말 것. **16:00 글로리아 명의 발송.** "Put it in writing, Elias. And this time, I will." 대사관이 그녀를 건너뛸 것, 대사는 점심에 안 부를 것.
  - 글로리아→머서: 캐나다는 이미 앎 — **어제(5/18) 나디아(쿠리 씨)와 점심**(나디아가 글로리아 것까지 주문). CSIS는 10일 11:40부터 두 번 다 출입 시각 기록.
  - 머서 요구: **금요일(5/21) 루킨 대면**(영사관이든 루킨이 안전한 곳이든). 일라이어스의 블러핑: 낯선 사람이 오면 토요일엔 사라진다. 일라이어스 "I'll try"(물어보겠다) ↔ 머서 "I'll see what I can do"(권고 전달 여부). 대면 성사 여부는 미기재.
- 정오 총영사실: 뉘앙스 — 일라이어스의 "I'll try" = 부숴서라도 / 랭글리의 "I'll see what I can do" = 이미 정해짐. 글로리아: "31년간 믿지 않는 걸 사천 건 서명, 은퇴 전 믿는 것 하나". **글로리아도 피에르뤽을 앎**: 4월 나디아에게 준 일정 시스템 기록의 이름을 "두 번 읽지 않았다", "난 아무것도 모른다". 지시: 피에르뤽은 계속 여권 쪽, 러시아인에게서 떼어 놓을 것. "Thank-yous get written down."
